# Changelog

## 0.1.0

Initial public source release.

- Custom in-game mpv control surface and movable HUD.
- Local media, direct URLs and yt-dlp-backed webpage URL support.
- Audio, subtitle and chapter browser with Skip Intro.
- Detached text subtitles.
- Detached local bitmap subtitles (PGS/VobSub/DVB/XSUB) using a synchronized helper libmpv core.
- Tight bitmap cue cropping and capped helper rendering for low overhead.
- Persistent horizontal centre snap for both text and bitmap detached subtitles.
- Video opacity slider with GPU-side alpha compositing.
